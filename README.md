# The Ranch Lab 🐂

A simple homelab repository for sharing operational scripts, documenting progress, and experimenting with useful services.

- [Architecture](docs/ARCHITECTURE.md): current machines and evolving plans.
- [Backlog](docs/BACKLOG.md): next steps and ideas.
- [Setup](docs/SETUP.md): laptop preparation, cluster installation, administration, and rebuild procedures.
- [Inference](docs/INFERENCE.md): local/LAN model serving, GPU lifecycle, model experiments, and client setup.
- [Monitoring](docs/MONITORING.md): Prometheus/Grafana topology, Windows/GPU telemetry, and host boundaries.
- `apps/`: deployable services with their owned source, assets, scripts, and manifests.
- `projects/`: self-contained lab projects that are not deployable services, when needed.
- `scripts/`: shared operational automation.
- `configs/`: shared reusable configuration files.
- `benchmarks/`: repeatable performance experiments and summarized results.
- `local/`: ignored private, machine-specific, generated, and temporary artifacts.
- `logs/`: daily progress and outcomes.
