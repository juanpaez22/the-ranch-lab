# The Ranch Lab 🐂

A simple homelab repository for sharing operational scripts, documenting progress, and experimenting with useful services.

- [Architecture](docs/ARCHITECTURE.md): current machines and evolving plans.
- [Backlog](docs/BACKLOG.md): next steps and ideas.
- [Ubuntu preflight](docs/UBUNTU_PREFLIGHT.md): updates and laptop lid configuration.
- `scripts/`: operational scripts.
- `configs/`: reusable configuration files.
- `logs/`: session notes and outcomes.
